    What the contract decides

    Settlement is a counter comparison. The page text below is the same rule as the source.

    1. Open. GEN is escrowed. Status is OPEN. Cancel returns it to the organizer.
    2. Lock. Validators fetch the authority URL and store the counters. Status becomes HOLDING. The release time is now plus the hold.
    3. Protest. Anyone can lock 10% of the prize as a bond. That does not ask a model if someone cheated. It waits for the next read.
    4. Recheck. A higher counter forfeits. The organizer receives 90%. The protestor, or the caller if there is no protest, receives 10% and the bond comes back. A failed fetch stays in the contract.
    5. Release. At or after the hold, a clean re-read pays the payee. A false protest’s bond is paid to the payee as well. An unreadable source does not release.
    6. Recover. 24 hours after the hold, if the source is still unreadable, the organizer can take the prize back. That status is source unavailable. It is not a ban finding.

    Authorities

    • steam_vac. https://steamcommunity.com/profiles/<id>/?xml=1 and the vacBanned tag. Friends-only profiles still publish this tag.
    • steam_roster. The same flag, plus VAC and game-ban counts inside the profile_ban_status element Valve renders. Text outside that element is ignored. If the element is missing, the read fails closed.
    • lichess. https://lichess.org/api/user/<id> and tosViolation: true. Lichess uses that flag for fair-play closures and for other Terms-of-Service closures. A player who closes an account without that flag does not forfeit the purse.

    Limits

    • The organizer chooses the roster and the payee. Wavehold does not replay the match.
    • A ban that already exists at lock is history. Only an increase during the hold forfeits.
    • Steam’s XML flag is a VAC ban. It is not a CS game ban. Use steam_roster for the banner Valve is currently showing.
    • Old VAC bans can remain in the XML after Valve removes the red banner from the profile page.
    • An unreadable profile sticks the funds until a later read works, or until recovery after the grace period.
